Shreyas Portfolio v2 is a cinematic, dark-themed personal portfolio built with Next.js 16, React 19, and TypeScript. It combines immersive WebGL shader effects, dual-engine animations (GSAP + Framer Motion), a Supabase-backed blog platform with an AI reading assistant, and a robust contact system — all deployed on Vercel.
